# 温馨改版（谷雨灵感）和 Undertale 音乐卡

- 用户反馈：现在看着压抑；不一定要用小鱼；名字最早是「谷雨」（容易撞名）；希望更温馨。音乐方面问 lvy 是怎么做的，提出要不就只放 Undertale。
- 查证：lvy 站直接托管 `/music/close-to-you.mp3`（`audio/mpeg`），属于自托管商业歌曲，不照搬。Toby Fox 官方 Bandcamp 有 UNDERTALE Soundtrack（album 2955245981，第 71 首 Undertale 的 track 1570961482），官方小播放器可以嵌入，高 42px，全球可播。大陆能否访问 Bandcamp 没有验证。
- 决定和实现：
  - 默认主题由深色改为浅色。浅色是米白底（#FBF6EC）加嫩芽绿、杏桃、鹅黄三团柔光，主色是茶绿 #4A9B78，文字是暖深灰褐。深色改成暖夜色（可可棕），不再用海军蓝。
  - 小鱼标志换成嫩芽 `SproutMark`（顶栏、简历、404、favicon 都换了）。插画卡改为嫩芽加细雨，配文「雨生百谷」。开启减少动效时，雨滴静止在固定位置。「谷雨」只作为视觉灵感，不当作名字使用。
  - 开屏动画保持原样，只换配色（米白、茶绿、杏色）。
  - 音乐卡改为 Bandcamp 官方嵌入，颜色跟随主题。删除网易云五首随机、洗牌逻辑和浮层。
- 验证：测试 26/26 通过（偏好默认值的测试先改为期望浅色，确认失败后再改实现；Bandcamp URL 校验先写测试）。lint、typecheck、默认构建和静态导出构建都通过。浏览器检查：浅色桌面、深色桌面、浅色手机三种情况下 1440×900 都是一屏，所有卡片没有内容溢出，Bandcamp iframe 正常加载（显示 Undertale），开屏动画出现且是新配色。各页面在两种宽度下都没有横向溢出，禁用 JS 时内容可读。
- 未验证：实际播放声音、大陆访问 Bandcamp、iOS Safari。

## 同日追加：持续播放、过渡动效、删除开屏

- 需求：切换到简历等页面时音乐不要停；页面切换和深浅色切换要有丝滑的过渡；删除开屏动画，改为首页卡片依次出现的动效。
- 持续播放：`PersistentPlayer` 挂在根布局里，在客户端路由切换时不会卸载。首页上它叠放在音乐卡的 `[data-player-slot]` 位置（用 ResizeObserver、resize 和 animationend 事件重新测量），其他页面停靠在右下角。整个过程只改 CSS 位置，不移动 iframe 的父节点，也不改 src。iframe 的地址在客户端第一次渲染时冻结，切换主题不会重新加载。验证：桌面和手机都按「首页 → 简历 → 项目 → 首页 → 切换主题」的顺序走一遍，iframe 是同一个元素（自定义标记还在），src 没变；首页时和占位的偏差是 [0,0,0]。
- 主题切换：`switchTheme` 用 `document.startViewTransition` 加 `flushSync`，新主题以圆形从点击位置扩散开。API 不可用或用户开启了减少动效时直接切换。验证：捕获到 `::view-transition-new(root)` 上的 `theme-reveal` 动画，减少动效时动画数为 0。
- 页面切换：本来尝试用 React `<ViewTransition>`（Next 16 文档说 App Router 不需要配置），但开发模式和生产构建下导航时 React 都没有调用 `startViewTransition`，原因没有查明，所以放弃了。改为每个页面挂载时，main 区域播放 CSS 的 `page-in`（上浮、淡入、去模糊）。首页不播这个动画，由卡片依次出现。验证：进入简历和项目页时捕获到 `page-in`。
- 开屏动画：已删除组件、`lib/intro.ts` 和 5 个相关测试。卡片入场改为模糊加上浮再轻微回弹（0.7s），每张卡错开 70ms；播放器等音乐卡出现后再淡入。
