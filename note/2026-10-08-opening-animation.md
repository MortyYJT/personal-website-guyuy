# 开屏动画参考

参考：https://emulisy.github.io/

本次通过生产浏览器刷新观察黑色全屏、白色爱心与旋转叉号、底部横条；检查当前页面加载层的 DOM 与内联 CSS / JS，确认爱心约 1 秒脉动周期，叉号每秒递增 45 度，横条先展开再收拢；最少停留 2 秒后，约 1 秒的竖向扩张 / 全屏扫屏退出。它是固定时序的装饰过场，不是真实加载百分比。

建议：保留爱心 / 旋转叉号 / 横条扩张的视觉节奏，用本站紫白配色；总时长约 1.4 秒，仅本标签页首次进入首页播放。提供跳过；低动态偏好和脚本不可用时直接显示内容。使用自写 TypeScript + CSS，不引入作者代码或额外动画依赖。需检查移动端、主题、导航、键盘和 reduced-motion。
