# 首页改版：毛玻璃卡片（bento）

- 决定：参考 lvyovo-wiki.tech（基于 YYsuni/2025-blog-public，MIT）。在本仓库用 CSS Grid 重做，不 fork：上游用 JS 计算绝对坐标排布卡片，390px 下卡片互相重叠，无 JS 时首屏不可读。没有复制上游代码或素材；页脚和 `THIRD_PARTY_NOTICES.md` 注明灵感来源。
- 保留：蓝白配色、开屏动画、中英双语、主题持久化。删除：打字机 Hero、分节和底部章节导航。
- 音乐：网易云官方外链播放器，用 facade 模式，点击后才加载 iframe。歌单 ID 还没给，填在 `src/content/site.ts` 的 `musicPlaylistId`。外链的 height 参数和能否播放要等拿到歌单后实测。
- 头像：用户提供的图片，裁成 320×320 的 `public/avatar.jpg`，最大显示 128px。出处未知，没有署名。
- 背景图：`site.backgroundImage` 预留了位置，目前为 null。
- 验证（2026-10-10，本地 dev 和生产 build，无头 Chromium 加 playwright-core）：
  - 测试 26/26 通过，新增问候、日历、数码管、网易云 URL 校验共 4 组，先 RED 后 GREEN。lint、typecheck、build 通过。
  - 1440 和 390 宽、深色和浅色下，首页、简历、项目、404 都没有横向溢出。
  - 键盘顺序依次是：跳到内容 → 导航卡 → 项目 → 社交 → 页脚。桌面端隐藏的顶栏不进入 Tab 顺序。
  - 禁用 JS 时，首页显示「你好」、名字、项目、关于和「--:--」。减少动效时卡片直接可见。
  - 没有在真机上验证，也没有做 Safari 的 backdrop-filter 实测。
- 同日改版：用户反馈「太大块了，要像原作者那样一屏放下」。改成紧凑卡片，宽屏（≥900px）下固定尺寸并在视口里居中。「关于」和「技术栈」移出首页（简历页里仍有），项目卡缩成「最新项目」小卡，页脚固定在底部。实测 1440×900 和 1280×720 的 scrollHeight 都等于视口高度，不用滚动。平板和手机仍然需要滚动，原站在手机上同样要滚动。
